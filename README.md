## Movie Model API

A scalable backend movie management system built with **Node.js**, **Express.js**, and **MongoDB** following RESTful API principles. This project focuses on creating a structured movie model with features like CRUD operations, filtering, sorting, pagination, validation, and clean API architecture.

### Features

* Create, read, update, and delete movies
* Advanced query filtering and sorting
* Pagination support
* MongoDB data modeling with Mongoose
* Input validation and error handling
* RESTful API structure
* Modular backend architecture
* Environment variable configuration
* Scalable controller-service structure

### Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* dotenv
* Postman for API testing

### Purpose

This project was built to strengthen backend development skills by implementing real-world API architecture, database modeling, and clean server-side logic.
